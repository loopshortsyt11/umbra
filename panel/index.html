Claude'u bağla

Umbra AI, Anthropic'in Claude Opus 5.5 modelini kullanır. Bunun için bir API anahtarı gerekir:

  1. console.anthropic.com adresinde hesap aç.
  2. API Keys bölümünden yeni anahtar oluştur ve kopyala.
  3. Aşağıya yapıştır.

Anahtar bu bilgisayarda Windows şifrelemesiyle saklanır; web sayfaları ona erişemez. Kullanım ücreti Anthropic hesabından düşer.
